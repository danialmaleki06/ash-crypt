# Пепельная крипта

Мрачная пиксельная action RPG: рыцарь с мечом и щитом против Пепельного Венца. Ранняя игровая сборка с одной ареной, драконом и руническим интерфейсом.

## [Играть в браузере](https://danialmaleki06.github.io/ash-crypt/)

Откройте ссылку и нажмите **«Начать бой»**. Устанавливать игру не нужно. Управление рассчитано на настольный браузер с WebGL2, клавиатуру и мышь.

| Ввод | Действие |
|---|---|
| WASD | Движение |
| Мышь / ЛКМ | Прицел / удар |
| ПКМ | Щит; при своевременном поднятии — парирование |
| Space | Перекат |
| Q | Ледяное копьё |
| E | Тяжёлый критический удар |
| R | Защитный барьер |
| Esc | Пауза |
| Enter | Начать или повторить бой |

Дракон парит в центре, взлетает и обрушивается на землю, ведёт огненное дыхание, бьёт лапой и выпускает обсидиановые снаряды. Выбегайте из рунического поля; выстрел можно отразить щитом.

HP — красный сосуд, мана — синий, выносливость — нижние зелёные сегменты. Свет, руны и боевые эффекты создаются процедурно.

В репозитории находится самостоятельная браузерная сборка. Для локального запуска можно раздать эту папку любым статическим HTTP-сервером, например `python -m http.server 8000`, и открыть `http://localhost:8000/`.
